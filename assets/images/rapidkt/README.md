# RapidKT announcement artwork

The community banner uses RapidKT's existing homepage illustration: strands of
expertise becoming structured AI skill blocks. It is copied unchanged from the
maintainer's RapidKT website into `static/img/rapidkt/expertise-to-skills.webp`.

See [provenance.json](provenance.json) for its source repository/path, checkout
revision, published source URL, byte count, and SHA-256. The source checkout is
read-only. CSS preserves the image ratio as a shaded banner background; no raster
editing or generated replacement was used.
